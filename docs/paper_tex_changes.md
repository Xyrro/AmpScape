# From the Markdown draft to the LaTeX submission — what changed (2026-10-16)

**Deliverable.** `paper/neurips/main.pdf` (28 pages: 9 content pages, references from page 10, appendices A–I, NeurIPS
checklist last), built with Tectonic 0.17.0 from `paper/neurips/main.tex` using **`neurips_2026.sty` (revision
2026-01-29, the latest available; `eandd` option = Evaluations & Datasets track, submission mode: anonymous with line
numbers)**. The Markdown draft is retired to `paper/draft_md_archive.md`. Rebuild: `scripts/paper_figures.py --skip-stats
--tex` (figures), `scripts/paper_tables_tex.py` (tables), then `tectonic main.tex` in `paper/neurips/`
(`$AMPSCAPE_TOOLS/bin/tectonic`).

## Form (from `docs/paper_style_memo.md`)
- Structure follows the accepted D&B papers: abstract (≈ 190 words) → introduction with a page-1/2 teaser figure and
  contributions in running text → related work → problem and tasks → the dataset → splits and OOD → metrics and
  protocol → baselines and results → many-query demonstration → limitations, ethics, maintenance → one
  reproducibility paragraph. Operational narrative (phases, incidents, drivers) is gone; the datasheet and the
  post-mortem are pointed to, not retold.
- Length: 9 content pages exactly (the Markdown draft was ≈ 5,800 words of main text with six tables, ≈ 11 pages).
  Main-text prose is now ≈ 3,000 words; the rest moved to the appendix or was cut.
- Tone: present tense, "we", observation → mechanism → implication, numbers with units and a comparison point; no
  bracketed file tags in the text — every paragraph that states a number carries a `% src:` comment instead, and
  `scripts/verify/check_draft_numbers.py --tex` checks every numeric token against those files (2,000 tokens in the
  main text and the 14 generated tables, 0 untraceable, 0 untagged).

## Content changes against the Markdown draft
- Related work compressed to one page and re-cited with the 54 BibTeX entries generated from
  `paper/sections/related_work.md` (`paper/neurips/references.bib`, keys = first author + year).
- The dataset section lost the layout listing and the solve-time sentence (both still in the appendix / card); the
  fidelity paragraph keeps the measured numbers (0.029 at M, 0.028 at L, 4.7 % above 5 %).
- Results: the "three observations" and "families fail in different places" paragraphs kept with fewer numbers;
  the T4 Pareto, scale-transfer, OOD, data-scaling and acceleration paragraphs condensed; the derivation moved to
  Appendix A in full.
- Limitations are a single numbered list (nine items, "not yet tested" folded in); the "claims the paper does not
  make" became one sentence; ethics/maintenance/reproducibility are three short paragraphs.
- Checklist: the 16 NeurIPS questions answered (Yes/NA with a one-line justification each).
